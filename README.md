# 準心之上 — 弓箭場

以原生 HTML5 Canvas 與 JavaScript 製作的單頁弓箭射擊遊戲，不需要安裝框架或第三方套件。遊戲動畫由 `requestAnimationFrame` 驅動，使用重力積分模擬拋物線飛行，移動靶環會依命中位置給予分數。

## 遊玩方式

在畫面左側弓手附近按住滑鼠、觸控或觸控筆，向後拖動以設定弓箭力道與仰角，放開後發射。短按即可使用基本力道射擊。靶心、黃圈、內圈、紅圈與外圈分別計 100、75、50、30、10 分；脫靶不計分。每回合有 8 支箭，打完會顯示總分。點選「重新開始」或按 `R` 即可重開；按 `Esc` 可取消目前瞄準。右上方按鈕可以切換以 Web Audio 合成的射擊與命中音效。

## 本機執行

以 Node.js 提供靜態伺服器：

```sh
npx --yes http-server . -p 3000
```

也可使用 Python：

```sh
python3 -m http.server 3000
```

然後開啟 `http://localhost:3000`。若使用滑鼠、觸控以外的操作，仍可直接短按畫布進行射擊。

## 技術細節

所有視覺物件（風景、弓、箭、移動靶、粒子特效與輔助軌跡）均以 Canvas 向量繪製；螢幕解析度依裝置像素比縮放並支援視窗調整。無外部遊戲引擎、圖片、伺服器端或遊戲資料上傳依賴；字型有本機系統字體回退。音效採瀏覽器 Web Audio API 合成，瀏覽器不支援時遊戲仍可正常遊玩。
